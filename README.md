# 盯盘盒子

在 VS Code 侧栏里看股票、指数与场内基金。腾讯行情，分类自选，持仓盈亏。

默认自选条目高 24px，名称、代码、现价、涨跌幅与持仓盈亏默认统一使用 8px 常规字重。左侧箭头与涨跌幅、中间现价、右侧上方名称和下方代码。箭头独占固定宽度，涨跌幅数字右对齐，不随箭头数量变化而错位。有持仓时，今日盈亏金额显示在独立的箭头列下方，涨跌幅与现价始终垂直居中，不额外增加条目高度；悬停可看完整金额与说明，点击仍可展开详情。名称显示为几个字（例如中国重汽→重汽、华东医药→华东、上证指数→上证），悬停可看全名，持仓面板仍显示全名。只有涨跌和收益数字使用红绿，背景与名称保持灰色。顶部今日盈亏、总盈亏始终保留，每币种约 36px。

## 使用

自选面板右上角设置支持 8–20px 行情字号、中文字体预设、主题、涨跌色、标题和图标。分类菜单可以按涨跌幅升降序排列，选择默认顺序可恢复拖拽。单击证券展开摘要，双击或从摘要打开图表，在编辑区查看日、周、月 K 线、成交量和 MACD。

「市场行情」分类提供上证指数、创业板指、科创50，以及美元／金衡盎司计价的伦敦金银。设置中可分别关闭两个贵金属报价，点击贵金属可查看报价详情。

安装后点击左侧 **盯盘盒子** 图标。也可按 `Ctrl+Shift+P`，运行 **盯盘盒子：打开盯盘**。

1. 点击 **新建分类**，或直接使用默认的“自选”。每个分类最多 10 只证券。
2. 点击分类右侧 **＋**，按名称或代码搜索。例如 `上证指数`、`腾讯`、`510300`、`159915`、`161725`。亦可输入完整代码，如 `sh000001`、`sz399001`、`sz399006`、`hk00700`、`bj920002`。裸 `000001` 会同时列出上证指数和平安银行，请核对市场与类型。
3. 右键证券直接打开小面板，同时填写数量与成本，点 **保存** 即可。已有持仓自动填入，行情刷新不打断输入，取消或 Esc 不保存。股票单位为股，基金单位为份，不是手。指数仅用于盯盘，不设置持仓。
4. 点击证券行展开详情。右键面板还可清空持仓、移至其他分类和移除证券。
5. 拖动分类标题可调整分类顺序；拖动证券到另一行前方可排序，拖到分类标题可移至该分类末尾。跨分类移动仍受每组 10 只与不重复规则约束，顺序自动保存。
6. 按 **Alt + Q** 隐藏盯盘并切回资源管理器，再按一次恢复。可在 VS Code 键盘快捷方式中搜索 **盯盘盒子：隐藏 / 显示** 修改按键；自选与持仓不受影响。

支持沪深北 A 股、港股、沪深指数，以及交易所上市的 ETF、LOF、QDII ETF / LOF 等场内基金。不包含场外申赎基金、港股字母代码指数、权证、美股，以及美元计价柜台。

## 盈亏与行情

- 上涨、盈利用红色，下跌、亏损用绿色，平盘为灰色。涨跌绝对幅度不足 3% 显示 1 根箭头，3%（含）至 6% 显示 2 根，6%（含）以上显示 3 根；上涨与下跌对称。金额以人民币、港币分别汇总；港股人民币柜台按人民币汇总。
- 今日盈亏估算 =（现价 − 昨收价）× 当前数量；今日收益率分母为昨收持仓市值。
- 持仓盈亏 =（现价 − 每股/份成本）× 当前数量；持仓收益率分母为成本总额。零分母显示“—”。
- 总收益率按汇总金额计算，不平均个股收益率。同一证券在不同分类共享持仓，总览只计算一次。
- 这里只记录当前持仓快照；不还原日内买卖，不记录已实现收益、分红或单独手续费。可录入券商已含费用的成本价。
- 自选或证券详情可见时，报价默认每 1 秒刷新，可用 `stockWatch.refreshSeconds` 调整到 1–60 秒。接口响应较慢或请求失败时会延长间隔。
- 展开自选条目可直接查看分时走势、每分钟成交量和 MACD。编辑区详情也提供「分时」标签。可见的分时图约每 1 秒查询腾讯的最新分钟数据，显示对应交易日。
- 详情可见时，日、周、月 K 线约每 15 秒从腾讯刷新，成交量与 MACD 随 K 线更新。报价和 K 线的数据时间取决于腾讯行情。

- 数据来自腾讯公开网页行情接口（`qt.gtimg.cn`、`smartbox.gtimg.cn`），并非交易所授权实时行情服务。港股可能延迟，请以显示的来源时间为准。场内基金展示交易价格，不是基金净值。
- 断网、缺失报价或历史行情会明确标注，历史涨跌不冒充今日盈亏；不完整汇总仅反映有效数据子集，不应视为完整账户收益。

## 数据与安装

无需账号和密钥，分类、持仓只保存在本机 VS Code 用户配置的插件存储中，不上传成本与数量，不启用遥测。网络请求仅用于证券搜索及行情查询。切换代码项目不会丢失自选。删除最后一个有关联的自选入口时，会确认是否一并清除持仓。

通过扩展面板右上角菜单 **从 VSIX 安装…** 选择 `stock-watch-box-0.2.3.vsix`。如图标未立即出现，可运行 **开发人员: 重新加载窗口**。

## 开发

### GitHub 远程修改与打包

源码上传到 GitHub 后，可在网页中编辑并提交文件。每次推送、Pull Request 或手动运行 Actions，都会检查、测试并生成 VSIX；在对应运行页面的 Artifacts 中下载 `stock-watch-vsix`。

发布新版本时，更新 `package.json`、`package-lock.json` 和打包命令中的版本号，再推送同版本的 `v` 标签（例如 `v0.1.14`）。工作流会自动创建 GitHub Release 并附上安装包。

GitHub Release 中的 VSIX 需要手动安装；当前插件不会读取 GitHub 源码或自动替换本地代码。要通过 VS Code 自动更新，需要使用真实 Marketplace Publisher ID 发布新版本，并开启 VS Code 扩展自动更新。Marketplace 发布者 ID 为 `local-stock-watch`；GitHub 工作流目前自动打包，商店版本需另行发布。

需要 Node.js 20+ 和 npm，VS Code 1.90+。

```sh
npm install
npm run check
npm test
npm run build
npm run package
```

按 F5 启动插件开发窗口。`npm run test:host` 在隔离的用户目录运行真实扩展宿主测试；默认使用本机 `D:\Programs\Microsoft VS Code\Code.exe`，其他机器可设置 `VSCODE_EXECUTABLE`。测试目录以 `.test-` 开头，不打入安装包。

本机 npm 若不在 PATH，可用 `node E:\股票\mcp\runtime\package\bin\npm-cli.js` 代替上述 `npm`。
